Comparison
The .bin bytes at flash base and every file-backed flash LOAD segment in each
.elf were compared. The comparison does not include unrelated saved settings
as executable bytes. The H7_v2 linker reserves 0x081E0000–0x081FFFFF for DATA.

Saved H7 build: 238120 bytes; 214862 byte positions differ.
Saved H7_v2 build: 270456 bytes; 259237 byte positions differ.
Both first differ at 0x08000004, the reset-vector entry, inside executable image.
Target reset vector: 0x0801CDF9.
Saved H7 reset vector: 0x0801921D.
Saved H7_v2 reset vector: 0x080207B9.
Both ELF flash LOAD segments also differ for each board.
Thus persistent settings alone cannot explain the mismatch. These ELF files
must not be treated as matching target symbols for address-level debugging.
Mismatch counts are positional byte comparisons, not counts of changed logic:
relocation/layout changes can cause many differences.

Effect on the rosserial investigation

The observed message MD5 strings are consistent with the local message types.
The previously supported shared-serialization race remains a hypothesis for
the installed firmware until its relevant implementation can be matched or
traced. Do not blindly use addresses from the existing ELF files to probe it.
